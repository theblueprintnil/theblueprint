# /inspire — Inspiration Design (Phase 1 of 8)

## Purpose

Start the loop the way the design says to: with an inspiration design, not code. Capture the idea, shape the screens, and scope this iteration before anything gets built.

## Instructions

1. Ask the user for the product idea, inspiration, or problem statement.
2. Write a short design brief in `docs/design/iteration-<N>.md` containing:
   - One-sentence product idea
   - Target user and their core job-to-be-done
   - Main screens described in words or ASCII (the dashboard and primary widget at minimum)
   - Must-have features for this iteration only
   - Design references, style constraints, and anything explicitly out of scope
3. Get the user's confirmation on the brief before moving on.

## Checklist

- [ ] One-sentence product idea captured
- [ ] Main screens described (dashboard, widgets)
- [ ] Must-have features for this iteration listed
- [ ] Design references and constraints noted

## When done

Advance the loop:

```
vibe-loop done inspiration
```

The next phase is animate (optional).
